# OpenMotion Agentic Video Studio Plugin (nexu-io/openmotion)

1. Click **OpenMotion Video** in **01 Content Creation** to generate a platform-matched `Motion.md` storyboard (`3:4`, `9:16`, `16:9`, etc.) and an interactive HTML5 motion-graphics preview.
2. If a local `nexu-io/openmotion` studio server is running (`http://localhost:3001`), it automatically connects to `/api/projects` for timeline editing and MP4 export.
3. You can also run the standalone studio via `npx skills add nexu-io/openmotion --skill openmotion`.
