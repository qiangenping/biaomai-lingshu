# Complete Operator Manual

## 1. Three-Column Workbench Overview
- **Topbar**: Switch active Industry Pack, Region Profile (`CN / Global / Self-Hosted`), Language (`中 / EN` in `<50ms`), Agent Engine (`OpenCode / Codex / Built-in`), and Dark/Light theme.
- **Left Sidebar**: Built-in Experts from active packs, Plugins & Skills Market, Isolated Browser Accounts, 24/7 Cron Schedules, and Remote IM Channels (Feishu / WeChat / DingTalk / Telegram).
- **Center Chat Stream**: Natural language task orchestration with collapsible MCP Execution Cards and amber Human-in-the-Loop Approval Cards.
- **Right Dynamic Canvas**: Automatically switches between Content Preview, Global Calendar, AI Browser Radar, and Lead CRM & ROI Attribution.

## 2. Using the AI-Native Embedded Isolated Browser
1. Click **AI Browser Radar** in the right canvas (or click **Expand Fullscreen** for widescreen browsing).
2. Create an isolated account container (`persist:bm-acc-<platform>-<id>`). Cookies and storage are strictly isolated per account.
3. Navigate to any public post or your own published work and click **Analyze Visible Comments**.
4. All phone numbers, emails, WeChat IDs, and UIDs are stripped automatically before intent scoring (`S / A / B / C`).
5. Click **Adopt & Prefill Reply** to populate the reply box. The browser highlights the input and **stops before clicking Send** so you retain 100% manual confirmation control.
6. Click **Add to Lead CRM** to move high-intent prospects into the 5-stage funnel (`New → Engaged → Qualified → Opportunity → Won`).

## 3. 24/7 Cron & Remote IM Control
- Open **Cron Schedules** to enable daily topic generation, scheduled publish health checks, or daily ROI digests pushed to Feishu / Telegram / WeChat.
- Approve pending publish tasks directly from your phone via WebUI or connected IM bots.
