# 标脉灵枢完整操作使用手册

## 1. 工作台总览与左侧折叠菜单

启动 **标脉灵枢 (`biaomai-operations-platform`)** 后默认直接进入 **全球获客工作台**（`/leadgen`）。全部功能模块统一收纳在左侧可折叠导航菜单的 **「全球获客工作台」** 下：

- **内容引流（Inbound）**：
  - `内容创作`：AI 多平台文案、出海多语改写、封面生图、AI 视频进度跟踪及无边框手机端实时预览。
  - `渠道分发`：17 大国内外平台独立 Cookie 隔离容器（`persist:bm-acc-*`）、排期队列与人工确认发布。
  - `社媒雷达`：隔离浏览器实时评论提取（强制 `pii-sanitizer` 脱敏）、竞品爆款结构提取、大模型语义精排与回填回复。
- **主动寻客（Outbound）**：
  - `企业寻客`：支持国内公司名批量挖掘、高德/百度地图商家提取、海外 Google Maps / LinkedIn / 欧美黄页提取、`dns.resolveMx` 邮箱验真、3 轮多语开发信与 WhatsApp 话术生成、IMAP 回信自动停发。
- **转化与生态（Convert & Ecosystem）**：
  - `线索 CRM`：5 阶段线索推进（`新意向 → 已回复 → 已留资 → 商机 → 已成交`）、短链 ROI 归因、爆款一键裂变与 CSV 导出。
  - `行业插件`：管理内置 4 大官方 `.bmpack` 行业套件、5 个双语国外开源插件及本地 `.bmpack` 热插拔安装。

在工作台顶部下拉框可一键切换 **5 大行业视角**（外贸制造业 / 跨境电商 / 政企招投标 / 本地生活商户 / 软件 SaaS 出海），自动填充行业卖点与目标市场关键词。

## 2. 初始配置指南（接口配置）

点击工作台右上角 **「接口配置」**，所有密钥均加密/持久化保存在本机，零上传：

1. **对话与文案大模型**：填入任意 OpenAI 兼容接口（如 DeepSeek、OpenAI 或本地 Ollama `http://localhost:11434/v1`）。
2. **AI 生图接口（可选）**：留空 API Key 默认复用上方模型 Key。
3. **AiToEarn MCP（可选）**：填入国内版（`aitoearn.cn`）、国际版（`aitoearn.ai`）或自建端点 `x-api-key`，即可开启 AI 短视频生成与云端短链点击同步。
4. **外贸/商务开发信 SMTP / IMAP & IM Webhook**：
   - **SMTP 发件箱**：支持 `smtp.163.com:465`、`smtp.qq.com:465`、`smtp.gmail.com:465`、腾讯/阿里企业邮等，填入邮箱与授权码（App Password）。
   - **IMAP 收信箱**：支持 `imap.163.com:993`（内置网易 RFC 2971 `ID` 身份申报兼容）、`imap.gmail.com:993` 等。
   - **IM Webhook**：填入飞书 / 企业微信 / 钉钉群机器人 Webhook，用于推送每日获客汇总。
   - **Crawl4AI URL（可选）**：本地运行 `Crawl4AI` 时填写 `http://localhost:11235/crawl`。

## 3. 社媒内容获客闭环（内容创作 → 渠道分发 → 社媒雷达）

1. **内容创作**：选择目标平台（如小红书 3:4、TikTok 9:16、LinkedIn 16:9）与语种，输入卖点后点击 **「AI 生成文案」**、**「生成封面配图」** 或 **「AI 短视频」**；在右侧手机预览区可直接行内微调标题与正文，点击 **「保存草稿并进入排期分发」**。
2. **渠道分发**：按平台创建独立隔离账号容器，首次在隔离窗口扫码/密码登录一次即可长期保持登录态；在排期队列点击 **「确认发布」** 完成人工门禁发布。
3. **社媒雷达**：在隔离浏览器打开任意帖子评论区，点击 **「读取隔离浏览器当前页评论」**（自动脱敏手机号/微信号/邮箱并按 S/A/B/C 分层）或 **「提取竞品爆款结构」** 送回创作工坊改写；点击 **「填入浏览器回复框」**（严格停在发送键前等待人工确认）及 **「+ 加入线索 CRM」**。

## 4. 国内企业与全球外贸主动寻客（企业寻客）

1. **国内模式（国内企业 / 地图）**：
   - 在文本框输入单个或批量国内公司全称（每行一家），点击 **「一键挖掘公司官网 / 电话 / 邮箱」**，自动聚合 360 搜索、百度移动端爱企查摘要与官网 `/contact` 页面联系方式（自动屏蔽用户自有发件箱）。
   - 或点击 **「高德地图搜商家」** / **「百度地图搜商家」** 在隔离浏览器搜索行业商户后，点击 **「从当前浏览器页面提取线索」**。
2. **海外模式（海外外贸寻客）**：
   - 输入行业关键词与目标国家，点击 **Google Maps / LinkedIn / Thomasnet / Europages / Alibaba** 打开目录搜索，一键提取真实采购商卡片。
3. **MX 验真、3 轮开发信与回信自动停发**：
   - 点击 **「抓邮箱 + MX 验真」** 探测官网公开邮箱并校验域名 DNS MX 记录。
   - 点击 **「AI 写多语开发信」** 自动生成 Day 1 / Day 4 / Day 9 跟进序列（含 WhatsApp 破冰话术）。
   - 点击 **「人工确认并通过 SMTP 发送」** 弹窗确认后发出 HTML+纯文本双排版商务邮件；随时点击 **「IMAP 检测客户回信」**，已回信客户将自动标记并暂停后续外发。

## 5. 线索 CRM、ROI 归因与定时巡检

- **线索推进与导出**：在 `线索 CRM` 推进客户阶段并一键导出 `biaomai-leads.csv`。
- **爆款 ROI 裂变**：在「渠道与内容 ROI 归因复盘」同步短链点击，点击 **「按此爆款裂变」** 回流创作工坊二次放大。
- **定时巡检**：点击顶部 **「定时巡检」** 开启每日巡检并推送汇总到飞书/企微/钉钉群。
