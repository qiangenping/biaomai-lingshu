## 2. 安全合规与人机协同红线
- **严禁静默群发**：无论是社媒评论回复、WhatsApp/LinkedIn 破冰话术，还是外贸 SMTP 开发信，均强制停在发送前由人工点击确认。
- **隐私零囤积**：`pii-sanitizer` 在评论评分前自动剔除手机号、微信号、邮箱与 URL。
- **全本地数据主权**：所有客户与配置均保存在本地 `userData/biaomai-studio-db.json`，零上传第三方服务器。

## 3. 定时巡检与飞书 / 企微 / 钉钉审批
点击工作台顶部 **「⏱️ 定时巡检 & IM」**，可一键开启每日巡检、手动触发 IMAP 客户回信检测（收到回信自动暂停后续跟进序列），并将每日待审批汇总推送到飞书/企微/钉钉群机器人。
