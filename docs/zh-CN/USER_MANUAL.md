# 标脉灵枢完整操作使用手册

## 1. 三栏式 AI 工作台总览
- **顶部控制栏**：自由切换当前行业包（如「运营获客包」）、运行区域（`国内 CN / 国际 Global / 本地 Docker`）、界面语言（`中 / EN` 毫秒级无重启切换）、底层引擎（`OpenCode / Codex / 内置 Agent`）与明暗主题。
- **左侧导航栏**：当前行业包内置专家广场、插件与技能市场、隔离浏览器账号管理、24/7 定时获客（Cron）及远程控盘通道（飞书/微信/钉钉/Telegram）。
- **中部对话流**：自然语言下达任务，实时展示可折叠的 MCP 工具执行卡片与琥珀色人工审批确认卡。
- **右侧动态画布**：随当前专家与任务自动联动渲染「获客预览 / 排期日历 / AI 浏览器雷达 / 线索 CRM & ROI」。

## 2. AI 原生内置隔离浏览器操作指南（免装 Chrome 插件）
1. 点击右侧 **`AI 浏览器雷达`** 画布（支持一键全屏展开）。
2. 新建或选择隔离账号容器（`persist:bm-acc-<平台>-<账号>`），每个账号 Cookie 与本地存储物理隔离，同屏运营多号绝不串号。
3. 在内置浏览器中打开目标帖子并展开评论区，点击顶部 **`「AI 意向雷达分析当前页」`**。
4. 系统自动通过 `pii-sanitizer` 剔除手机号、微信号、邮箱与 UID，并按 S/A/B/C 级输出意向评分与双风格回复草稿。
5. 点击 **`「采纳并填入回复」`** 后，浏览器自动定位评论框填入文案并**停在发送按钮前高亮提示**，由您人工确认点击发送。
6. 点击 **`「加入线索 CRM」`** 将高意向潜客纳入五阶段跟进看板（`新意向 → 已互动回复 → 留资 → 商机 → 成交`），并可随时导出 CSV。

## 3. 24/7 无人值守 Cron 与手机远程控盘
- 在左侧「24/7 定时任务」中可开启每日热点选题、定时发布巡检、每日 ROI 战报推送。
- 绑定飞书 / 微信 / 钉钉 / Telegram 后，外出时可直接通过手机下达创作任务并远程审批排期。
