# 标脉灵枢（OpenGrowth）完整操作手册

本手册面向初次使用的业务团队与开发者，覆盖从首次配置模型到完整跑通「内容获客 + 主动寻客 + CRM 成交」的全流程操作。

---

## 一、首次启动与基础配置

### 1. 配置大模型（任选其一，自动同步）
1. 在左侧底部点击 **「设置 → 模型」** 添加你的 OpenAI 兼容服务商（如 DeepSeek、OpenAI、通义千问、本地 Ollama 等）与 API Key。
2. 切回 **「全球获客工作台」**，右上角状态胶囊会自动亮起绿点并同步当前模型；若在主设置中删除了模型，工作台也会自动清空缓存。
3. 如需单独覆盖工作台模型、配置独立 AI 生图 Key、外贸 SMTP/IMAP 邮箱或飞书/企微 Webhook，可点击右上角 **「接口配置」**，在「大模型与生图」「外贸邮箱」「通知与本地爬虫」三个标签页中按需填写。

### 2. 选择行业视角
- 在工作台顶部标题右侧下拉框选择您的行业场景（外贸制造业 / 跨境电商 / 政企招投标 / 本地生活 / 软件 SaaS 出海 / 自定义），系统会自动预置对应行业卖点与寻客关键词。

---

## 二、路径 A：社媒内容引流闭环（01 → 02 → AI 浏览器 → 04 → 06）

### 第 1 步：01 内容创作（一键全套生成）
1. 选择目标发布平台（如小红书 `3:4`、抖音 `9:16`、LinkedIn `16:9` 等）与输出语种。
2. 输入一句话产品卖点或客户痛点，点击主按钮 **「一键生成全套内容（文案 + 封面 + 动效）」**。
3. 右侧手机预览区会实时呈现生成的标题、正文 CTA、品牌视觉封面与 **OpenMotion 动效视频**（点击右上角 `切封面图 / 切动效` 可自由切换）。
4. **哪不好再改哪**：标题和正文可直接点击右侧手机预览行内编辑；下方提供 `重生成文案`、`换封面`、`换动效` 单点微调按钮；所有保存过的草稿可在「最近创作记录」中一键回填。

### 第 2 步：02 渠道分发 & 内置 AI 浏览器发布
- **极速发布**：在创作页直接点 **「立即去 AI 浏览器发布」**，系统自动保存草稿、复制标题正文并打开内置 AI 浏览器的对应平台创作者后台。
- **排期发布**：点 **「加入排期日历」** 后跳转至「渠道分发」顶部置顶排期队列，随时点击 **「去 AI 浏览器发布」**。
- **合规二段式确认**：在内置 AI 浏览器右侧副驾驶点击 **「一键回填到当前页面」**，人工检查封面与标签后在平台点击发布，随后点击 **「标记已发布」** 计入 ROI 归因。

### 第 3 步：03 内置 AI 浏览器 + 04 社媒意向雷达
1. 在左侧点击 **「AI 浏览器」**（或在社媒雷达点击 **「去 AI 浏览器逛帖子并抓评论」**），用快捷书签打开小红书、抖音、知乎、LinkedIn 等目标帖子页。
2. 点击右侧副驾驶 **「抓取本页评论 → 社媒雷达」**（或点击 **「提取竞品爆款 → 内容创作」** 一键改写爆款）。
3. 进入「社媒雷达」后，系统已自动完成真实昵称提取、PII 隐私脱敏与 S/A/B/C 意向打分；点击 **「大模型语义精排与定制回复」** 生成高转化回复，点击 **「+ 加入线索 CRM」** 入库。
4. *(离线体验)*：也可直接点击 **「一键填入示例评论测试」**，零账号登录即可完整体验脱敏、打分、精排与入库。

## 三、路径 B：全球与国内企业主动寻客（05 → 06）

### 1. 国内企业与地图寻客
- 切换至 **「国内企业 / 地图」** 模式：
  - **批量公司深挖**：每行输入一家公司全称，点击 **「一键深挖官网 / 电话 / 邮箱」** 自动提取公开联系方式；
  - **地图搜商家**：点击高德地图 / 百度地图（或在内置 AI 浏览器中搜索），通过右侧 AI 副驾驶 **「提取本页企业 → 企业寻客」** 批量入池。

### 2. 海外外贸 B2B 寻客
- 切换至 **「海外外贸寻客」** 模式：
  - 填写行业关键词、目标国家与开发信语种；
  - 点击 Google Maps / LinkedIn / Thomasnet / Europages / Alibaba 打开目录页 → 提取企业列表 → 点击 **「官网深挖 + MX 验真」** 校验邮箱有效性 → 点击 **「AI 写开发信」** 生成 3 轮序列 → 人工确认后 SMTP 发送或回填 WhatsApp/LinkedIn 私信。
  - 点击 **「入库 CRM」** 自动将公司名、邮箱、电话与官网写入线索 CRM。

## 四、06 线索 CRM 与开源 CRM 双向同步

1. **本地 5 阶段看板**：支持 `看板管道（Kanban）`、`数据列表（Table）`、`ROI 归因` 三视图切换；支持关键词搜索、S/A/B/C 筛选、新建线索、卡片左右推进阶段与 CSV 导出。
2. **详情抽屉**：点击任意线索卡片弹出右侧抽屉，可编辑联系人、公司、邮箱、电话、预估成交金额与跟进备注。
3. **接入开源 Twenty CRM / Atomic CRM**：
   - 点击顶部 **「配置开源 CRM」**，选择 `Twenty CRM (twentyhq/twenty)`、`Atomic CRM (marmelab/atomic-crm)` 或 `通用 REST Webhook`，填入服务地址与 Bearer Token；
   - 点击 **「推送至 Twenty」** 即可将本地高意向线索一键同步至自建开源 CRM。

---

## 五、07 行业插件热插拔与本地 OpenMotion Studio

1. **安装与卸载**：在 **「行业插件」** 页面可查看全部已加载插件，点击右上角 **「安装本地 .bmpack 插件」** 可即时导入任意符合 `aion-extension.json` 规范的本地插件；点击卡片右下角 **「卸载」** 可随时移除。
2. **新对话 `/` 全量调用**：在左侧 **「新对话」** 输入 `/` 即可直接唤起全部已安装插件技能（中英文描述随界面语言自动切换）。
3. **启动本地完整版 OpenMotion Studio**：在 `OpenMotion 动效视频工坊插件` 卡片点击 **「启动本地完整版 Studio」**，首次会自动拉取 `nexu-io/openmotion` 并构建启动本地服务（`http://localhost:3001`），运行中可随时打开时间轴编辑与导出 MP4 或点击停止。
